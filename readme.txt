پایش زمان‌بندی‌شدهٔ سایت‌ها، ساختهٔ کاریونیت.

== Description ==

تیک‌بان افزونهٔ پایش کاریونیت است. نام، آدرس، روزهای بازدید و ساعت بازدید هر سایت را می‌گیرد، سر موعد همان آدرس را چک می‌کند و آخرین وضعیت را سبز یا قرمز نشان می‌دهد.

اگر چک خطا بدهد، لاگ همان رکورد باز می‌شود. تست آنی هم بدون انتظار برای ساعت مقرر وضعیت را همان لحظه می‌سنجد. در صورت تمایل، نتیجه به بله هم فرستاده می‌شود.

== Installation ==

افزونه‌ها، افزودن، بارگذاری tickban.zip، نصب و فعال‌سازی. منوی تیک‌بان در پیشخوان است.
