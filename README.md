# تیک‌بان

افزونهٔ پایش کاریونیت. نام، آدرس، روز و ساعت بازدید سایت‌ها را می‌گیرد، سر موعد چک می‌کند و آخرین وضعیت را سبز یا قرمز نشان می‌دهد.

یک ربات بله و یک ربات تلگرام برای همهٔ سایت‌ها کافی است. بعد از هر چک، برای هر سایت یک پیام جدا می‌رود: نام سایت، دامنه، وضعیت، ساعت و تاریخ هجری شمسی.

سازنده: کاریونیت — https://carunit.ir
